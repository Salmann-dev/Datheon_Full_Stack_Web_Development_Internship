# Task 2: Dynamic Task Manager & Productivity Tracker

A task management app built with plain HTML, CSS and JavaScript. Tasks are saved in the browser with `localStorage`, so they stay after a page refresh.

## Features

- Add, edit, delete and complete tasks (full CRUD)
- Priority levels (low, medium, high) shown with a color marker
- Optional due dates, with overdue tasks highlighted
- Filters: All, Active and Completed
- Progress bar showing the share of completed tasks
- "Clear completed" button and a live count of tasks left
- Data persists in `localStorage`
- Responsive layout for phones and desktops

## Tech Used

- HTML5
- CSS3 (custom properties, flexbox, grid)
- Vanilla JavaScript (ES6+)
- Browser `localStorage`

## How to Run

No install is needed.

1. Open `index.html` in a browser, or
2. Use the VS Code "Live Server" extension for auto-reload.
