Featured production project: Copyforge — an AI copywriting platform

Copyforge

AI-Powered Copywriting Platform for Small Businesses

A full-stack copywriting web tool that generates on-brand product descriptions and platform-specific social media posts. Users define their brand voice parameters once, and Copyforge generates copy tailored to that tone — powered by Google's Gemini API through a secure serverless backend.

  • ✓ Serverless proxy architecture (Vercel Functions) ensures Google Gemini API keys are never exposed to client browsers.
  • ✓ Custom brand voice input allows users to produce copy that truly reflects their editorial tone.
  • ✓ Clean, dependency-free UI built with plain semantic HTML5, CSS3, and JavaScript.

AI Resume Analyzer

AI-Powered Resume Analysis Tool

A web app that analyzes a resume (PDF or Word) and, optionally, a target job description, then returns a match score out of 100, key strengths, areas for improvement, missing keywords, and a summary verdict, powered by Google's Gemini API.

  • ✓ Flask backend extracts resume text with pdfplumber (PDF) and python-docx (Word) before sending it to Gemini.
  • ✓ An optional job description lets the analysis score the resume against a specific role.
  • ✓ Plain HTML, CSS, and vanilla JavaScript frontend with drag-and-drop upload, with no frameworks.
